# Smart Placement Prediction System Using Machine Learning

The Smart Placement Prediction System is a machine learning-based web application developed using Python, Flask, HTML, CSS, and Scikit-learn. The system predicts whether a student is likely to be placed based on academic and skill-related information such as CGPA, internships, projects, workshops, aptitude score, soft skills, SSC marks, and HSC marks.

The application uses the Random Forest Classifier algorithm to generate accurate placement predictions along with the placement probability percentage. It also provides personalized improvement suggestions to help students identify areas that need improvement for better placement opportunities.

## Features
- Student-friendly web interface
- Placement prediction using Machine Learning
- Placement probability percentage
- Personalized improvement suggestions
- Random Forest Classifier model
- Responsive UI with Flask

## Technologies Used
- Python
- Flask
- HTML5
- CSS3
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Seaborn

This project was developed as a college mini project to demonstrate the practical application of Machine Learning in student placement prediction and career guidance.
